# slotradar

Live Solana mainnet as a **cold-war CRT radar scope**.

Sweep arm ticks with the slot clock. Blips are recent txs — phosphor color by program family. Scope clutter / bloom ≈ fee pressure. Failed txs paint as red afterglow ghosts. Kill the transmitter to freeze a sweep.

Not an explorer. Not a dashboard. Not a newspaper.
